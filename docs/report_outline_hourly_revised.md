# 小时级 PM2.5 预测项目报告目录大纲（基于当前真实实验结果修订）

本目录根据当前仓库中的真实实验结果重新整理，主线任务已经统一为：

- `h1`：未来 1 小时单步预测
- `seq6`：未来 6 小时逐小时预测

修订时重点参考了以下真实结果与分析产物：

- `outputs/hourly/overall_metrics_summary.csv`
- `outputs/hourly/feature_ablation.csv`
- `outputs/hourly/aqi_bucket_metrics.csv`
- `outputs/hourly/high_pollution_error_analysis.csv`
- `outputs/hourly/hourly_error_by_dayperiod.csv`
- `outputs/hourly/cross_city_metrics.csv`
- `outputs/hourly/analysis_notes.md`

当前最重要的实验结论包括：

- `h1` 任务最优模型为 `LSTM`
- `seq6` 平均表现最优模型为 `XGBoost`
- 随着预测步长从 `h1` 增加到 `h6`，多步预测误差整体持续增大
- 特征工程对结果影响显著，尤其是滚动统计、趋势特征和气象增强特征
- 高污染场景和跨城市泛化仍然是当前方法的主要难点

因此，下面的大纲保留了真正有价值、且能被当前真实数据支撑的深入分析标题，同时删去了过细、过散、不利于成文的小标题。
